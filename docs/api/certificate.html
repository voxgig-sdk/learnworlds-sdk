| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | course_id | query | string | No | Filter by course title id | | user_id | query | string | No | Filter by user id or email | | Authorization | header | string | Yes | The Bearer token | | Lw-Client | header | string | Yes | The school Client ID | | page | query | integer | No | Filter by the page number.

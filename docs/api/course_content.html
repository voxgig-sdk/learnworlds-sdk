create

POST /v2/courses/{id}/sections

Operation ID: post-courses-id-sections.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | Course Id | | Authorization | header | string | Yes | The Bearer token | | Lw-Client | header | string | Yes | The school Client ID |

Request body

application/json

The request body is object.

Responses

201: Created

application/json

Property Type Required Description
id string No Unique identifier of the course
sections array of object No Sections of the course
sections[].access enum: public, premium, soon, private No Access type of the section
sections[].description string,null No Description of the section
sections[].drip object,null No Drip feed details of the content. Null value indicates that the course has drip feed option as disabled
sections[].drip.body string,null No Body of the notification
sections[].drip.date null,number No Drip feed date
sections[].drip.days integer No Drip feed days
sections[].drip.notify boolean No Setup an email notification to be sent to students once this section becomes unlocked
sections[].drip.subject string,null No Subject of the notification
sections[].id string No Unique identifier of the section
sections[].learningUnits array of object No Learning activities of section
sections[].learningUnits[].icon string No Type icon of learning activity
sections[].learningUnits[].id string No Unique identifier of learning activity
sections[].learningUnits[].subtitle string No Subtitle of learning activity
sections[].learningUnits[].title string No Title of learning activity
sections[].learningUnits[].type string No Type of learning activity
sections[].title string No Title of the section
title string No Title of the course

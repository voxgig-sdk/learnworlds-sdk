create

POST /v2/community/spaces

Operation ID: post-v2-community-spaces.

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | Lw-Client | header | string | Yes | The school Client ID | | Authorization | header | string | Yes | The Bearer token |

Request body

application/json

Property Type Required Description
access enum: public, private, standalone Yes Access type of the space
collectionId string No Unique identifier of the collection in which the space will be displayed. In case of public or private access the field is required, while in case of standalone an error will be returned
description string No Description of the space
hidden_from_community boolean No Indication whether the space is hidden from community
is_invitation_required boolean No Indication whether users are sent an invitation to join or are directly added to space. It is applicable only for spaces with private access.
is_members_allowed_to_view_members boolean No Indication whether users can view other users in space. It is applicable only for spaces with private access.
title string Yes Title of the space

Responses

201: OK

application/json

Property Type Required Description
access enum: public, private, standalone No Access type of the space

description string No Description of the space

id string No Unique identifier of the space
is_invitation_required boolean No Indication about whether users are sent an invitation to join or are directly added to space
is_members_allowed_to_view_members boolean No Indication about whether users can view other users in space
owner object No Information about the space owner
owner.id string No The id of the creator of the space
owner.username string No The username of the creator of the space
title string No Name of the space
usages array of object No List of space usages in the platform
usages[].courseId string No Unique identifier of the course the space is used
usages[].type enum: ebook No Type of usage location
usages[].unitId string No Unique identifier of the unit the space is used
